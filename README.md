Официальные дистрибутивы сервиса «УЗИ голосом» - помощника врача ультразвуковой диагностики в оформлении протоколов: https://uzigolosom.ru
Надиктуйте исследование, получите протокол. Ассистент документации без диагностических функций: каждое значение проверяет и подтверждает врач.

В этом репозитории только дистрибутивы (APK, контрольные суммы, описание версий). Исходного кода здесь нет.

### Установка

1. Откройте ссылку или отсканируйте QR-код на телефоне и скачайте APK.
2. Разрешите установку из этого источника, когда Android спросит (Настройки → Установка неизвестных приложений).
3. Откройте приложение и войдите по адресу почты вашего кабинета: код из 6 цифр придет на почту. Без пароля и без карты.
4. Android 8.0 или новее. Разрешения: микрофон (диктовка), уведомления (результаты обработки).

Приложение само проверяет новые версии и предлагает их скачать. Файл можно сверить по контрольной сумме SHA-256 из `releases/CHECKSUMS.txt`.
